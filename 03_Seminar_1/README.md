# Chan-sam Lee Portfolio

기계 R&D 및 기구설계 역량과 프로젝트 경험을 소개하는 개인 포트폴리오입니다.

실측값을 설계 조건으로 바꾸고, 이론과 구조해석으로 설계를 검토하며, 제작·조립·시험에서 확인한 문제를 다음 설계에 반영해 온 경험을 정리했습니다.

## 핵심 역량

- **실측 기반 기구설계**  
  실제 사용 환경과 치수 편차를 확인하고 기구의 형상, 이동 범위와 결합 구조에 반영합니다.

- **이론 계산과 구조해석 검산**  
  해석 결과를 이론값과 비교하고, 변형 양상과 지배적인 파손 모드를 바탕으로 보강안을 검토합니다.

- **시제품 통합과 협업**  
  기구·전장·제어가 함께 작동하도록 인터페이스를 맞추고, 모듈 간 설계 변경을 조율합니다.

## 페이지 구성

1. 한 줄 소개
2. 핵심 역량
3. 주요 프로젝트
4. 대표 프로젝트 상세
5. 자기소개형 카드뉴스
6. 연구 및 활동 경험
7. 사용 도구

## 주요 프로젝트

| 프로젝트 | 담당 역할과 주요 내용 |
| --- | --- |
| RFID 자전거 잠금장치 | 기계 파트 주도. 현장 실측, 기구설계, 제작·조립과 실거치대 기능 시험 |
| 다단 트레킹 폴 좌굴 개선 | 이론 계산, ANSYS 모델 구축, 검산과 보강안 비교 주도 |
| 형상변환 태양광·풍력 파라솔 | 5인 팀장. 모듈 간 설계 조율과 축소 시제품 통합 |
| 수중 탐색·구조 보조 로봇 | CATIA 설계, FDM 제작·조립과 수밀 구조 검토 |
| 저널 베어링 압력 가시화 | 베어링부 설계·도면, 이론값 산출과 실험 |
| 스퍼기어 제조공정 분석 | 공정 분석 보고서 총괄, 개선안 검토와 최종 발표 |

대표 사례인 트레킹 폴 프로젝트에서는 이론 검산과 좌굴 모드 분석을 통해 보강안을 수정했습니다. 최종 3·4단 십자 리브 모델의 구조해석에서 좌굴하중을 453.4 N에서 736 N으로 약 62.3% 높였습니다. 해당 수치는 구조해석 결과이며, 실물 시험은 후속 검증 항목으로 표시했습니다.

## 연구와 활동

CHAMP Lab 학부연구, 폐 PCBA 전처리 장치 JABJA, 경기청년 갭이어 함께하개, RED 운영 및 ANSYS 스터디 경험을 함께 소개합니다.

프로젝트별로 개인 역할과 팀 결과, 해석 결과와 실물 시험의 검증 범위를 구분했습니다.
